# Glossary

| Term | Meaning here |
| --- | --- |
| PAT | Personal access token. The boss key for GitHub API writes. |
| Fine-grained token | PAT with per-repo permissions. Easy to under-scope. |
| Classic token | Older PAT style; `repo` scope unlocks repository writes. |
| TexMexBot | Your docs-leaning Grok Bot assistant. |
| Unhinged (adj.) | Enthusiastic shipping energy; still respects `rm -rf` boundaries. |
