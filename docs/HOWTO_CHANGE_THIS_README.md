# How to change this README without summoning chaos

1. Edit locally or ask TexMexBot.
2. Keep the top section scannable: what / why / how in under 20 lines.
3. Put deep detail in `docs/`, link it from the table.
4. Prefer examples over adjectives.
5. Commit message style: `docs: …` for documentation-only changes.

## Checklist before you merge yourself

- [ ] Links resolve
- [ ] Code fences have a language tag
- [ ] No secrets, tokens, or "temporary" passwords
- [ ] Someone who did not write it can follow the Quick start
